# David Cachaza

I build web applications, internal tools, and self-hosted software, with a focus on practical workflows and maintainable systems.

My recent work brings together TypeScript, Next.js, databases, and background workers—from reusable foundations for internal applications to a searchable personal media library.

## Selected projects

| Project | What it does |
| --- | --- |
| [Internal OS Starter](https://github.com/Cachaza/internal-os-starter) | A foundation for organization-owned internal tools, with authentication, typed APIs, PostgreSQL, and durable background jobs. |
| [create-internal-os](https://github.com/Cachaza/create-internal-os) | A CLI that scaffolds an application from Internal OS Starter, with interactive setup and reproducible starter versions. |
| [Curator](https://github.com/Cachaza/instagram-curator) | A self-hosted library that imports Instagram posts, transcribes audio with Whisper, and organizes content with Codex. |

## Technologies I work with

- **Web:** TypeScript, React, Next.js, Tailwind CSS, and shadcn/ui.
- **Backend and data:** Node.js, Bun, tRPC, Drizzle ORM, PostgreSQL, and SQLite.
- **Development and deployment:** pnpm, Turborepo, Docker, and GitHub Actions.
- **AI and media workflows:** Whisper, Codex integrations, and FFmpeg.

Explore the repositories above for setup instructions, architecture details, and development checks.
